# Kraul Engine — overview

## Role

Kraul Engine is the engine project associated with Arakul Studio. Arakul Studio is the user-facing creative workspace; Kraul owns its engine-level architecture and API documentation.

## Scope

The project direction includes image-processing workflows such as background removal, foreground isolation, and handling transparent edges/alpha channels. These are scope statements, not proof that every capability is currently implemented.

## Boundaries

- Kraul Engine: engine code, processing contracts, API, technical docs.
- Arakul Studio: workspace and user-facing product experience.
- QKC Engine: separate quiz/test engine.

## Status vocabulary

- **Implemented:** verified in current source code and tests.
- **In progress:** implementation exists but is incomplete or not yet verified.
- **Planned:** intended future work.
- **Unverified:** not yet audited against the current source.

Use these labels in the API reference and feature lists so readers can distinguish working behavior from project goals.
