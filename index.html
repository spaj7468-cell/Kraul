01 / overview

One engine. Its own technical home.

Arakul Studio is the workspace users interact with. Kraul Engine is the separate engine layer intended to provide reusable processing capabilities and a documented API.

01 · PURPOSE

Image workflows

Project scope includes image-processing tasks such as background removal, foreground isolation and workflows involving transparent edges or alpha channels. Feature availability must be verified against the code.

Scope
02 · API

A documented interface

Kraul has its own API. Its exact exports, parameters, accepted inputs, return values and error behavior should be documented from the actual implementation.

API reference
03 · INTEGRATION

Arakul Studio

Kraul and Arakul Studio are related but not interchangeable: the studio is the product/workspace, while the engine is the technical layer maintained in this repository.
