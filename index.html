01 / overview

One engine. Its own technical home.

Arakul Studio is the workspace users interact with. Kraul Engine is the separate engine layer intended to provide reusable processing capabilities and a documented API.

01 · PURPOSE

Image workflows

Project scope includes image-processing tasks such as background removal, foreground isolation and workflows involving transparent edges or alpha channels. Feature availability must be verified against the code.
